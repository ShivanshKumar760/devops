3.for local image load the image into cluster so that it does not have to pull:
 kind load docker-image api:local --name test-cluster

4.check the image: docker exec -it test-cluster-control-plane crictl images
5.create a sample file for deployment.yml: kubectl create deployment api-deploy --image-name=api:local --dry-run=client -o yaml > sample.yml
6.kubectl get deploy
7.kubectl get pods
8.kubectl get svc
9.kubectl expose deployment api-deploy --name=api-deploy-service --type=NodePort --port=3000 --target-port=3000 --dry-run=client -o yaml > service.yml
10.if we want to create service from scratch :
kubectl create service nodeport api-deploy-service --tcp=3000:3000 --dry-run=client -o yaml > service.yml

11.port forwarding:
kubectl port-forward svc/api-deploy-service 8080:3000
